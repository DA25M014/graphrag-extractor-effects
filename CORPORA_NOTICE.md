## Provenance and modifications

The texts were obtained from Project Gutenberg and the Project Gutenberg
header and footer, including its license and trademark text, were removed
before the files were committed. Project Gutenberg applies its trademark
terms to texts distributed with that boilerplate; these files carry none
of it, and this repository makes no use of the Project Gutenberg
trademark.

One factual remnant is retained deliberately: `moby_dick.txt` contains an
original transcriber's note recording that the etext combines a Virginia
Tech ERIS source with a Project Gutenberg source, checked against a hard
copy. It is left in place because deleting a provenance record would be
worse than keeping it, and because the extraction pipeline sees the file
as committed, so removing it now would invalidate the shipped results.

If you redistribute these texts, the public domain status above travels
with the works themselves and not with this repository.
